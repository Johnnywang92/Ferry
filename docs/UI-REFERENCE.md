# Ferry UI 设计参考

来源：仓库根目录 `Ferry.html`（自包含 bundle，5 屏，需 JS 渲染）。
本文件是从设计稿提取的实现依据，M2/M3/M4 的 UI 一律以它为准。

设计稿共 5 屏：**主窗口·浅色**、**主窗口·深色**、**新建连接**、**文件冲突（覆盖/跳过/重命名）**、**传输失败**。

## 2. 主窗口布局

基准窗口 **1280×800**，圆角 12px，1px 描边。自上而下：

| 区域 | 尺寸 | 内容 |
|---|---|---|
| 标题栏/工具栏 | 高 **56px**，padding 0 16px，gap 16px | 左：交通灯占位 216px；中：图标按钮组（每钮 **56×44**，图标 20px + 11px 文字）；右：连接状态胶囊 + 搜索框 |
| 主体 | 左侧栏 **220px** + 双栏列表 | 侧栏条目高 30px，分区标题 11px |
| 传输队列面板 | 行高 44px，头部 26/28px | 见 §2.3 |
| 状态栏 | 高 ~26px | 左/中/右三段 |

### 2.1 工具栏动作（设计稿 aria-label 原样）

`上传所选`、`下载所选`、`新建文件夹`、`刷新`、`同步比较`、`断开连接`、`添加站点`、`上一级`、`上传到远程`、`下载到本地`
可见标签（图标下 11px）：**上传 / 下载 / 新建文件夹 / 刷新 / 同步**。

### 2.2 侧栏与双栏

- 侧栏两组：**站点**（生产 Web·SFTP、预发布·SFTP、备份 NAS·FTP、静态资源·FTPS，协议以胶囊标签呈现）+ **本地位置**（桌面、文稿、下载、Projects）。
- 左栏头：`本地` 标签 + 路径 `~/Projects/mubo-site/dist`；列：**名称↑ / 修改时间 / 大小**（无权限列）。
- 右栏头：`远程` 标签 + 路径 `/var/www/html`；列：**名称↑ / 修改时间 / 大小 / 权限**。
- 权限列用 `rwxr-xr-x` 等宽字；目录 `rwxr-xr-x`、`uploads` 为 `rwxrwxr-x`。
- **`.htaccess` 直接出现在列表里** → 印证方案"隐藏文件默认显示"。
- 时间列两种格式并存：当天显示 `今天 09:12`，当年显示 `10月13日 21:05`，更早显示 `9月28日`。
  本地列只到分钟，远程目录项可省时间到日。

### 2.3 传输队列面板

头部：`传输队列` + `1 项进行中 · 1 项失败 · 1 项等待` + 右侧筛选分段 **全部 / 进行中 / 失败**。
每行：方向标签（上传/下载）+ 文件名 + 路径映射 `本地路径 → 远程路径`（超长截断为 `/var/www/h`）+ 进度条 + 状态行。
状态行文案：
- 进行中：`62% · 8.4 MB/s · 剩余 12 秒`
- 失败：`失败 · 连接被重置 · 重试`（"重试"为可点）
- 等待：`等待中`

### 2.4 状态栏

左：`本地 已选 2 项 · 共 13 项` ｜ 中：`↑ 8.4 MB/s  ↓ 0 KB/s` ｜ 右：`远程 共 13 项 · 加密连接 · UTF-8`

## 3. 连接状态胶囊

工具栏右侧：`● 生产 Web` + `SFTP · 已连接 · 32 ms`。
**`32 ms` 是实时 RTT**，方案 v2.3 只有心跳、没有 RTT 探测与展示要求 → 新增需求。

## 4. 新建连接（表单屏）

副标题：`连接到 SFTP、FTP 或 FTPS 服务器。`

| 字段 | 形态 |
|---|---|
| 名称 | 文本，占位 `例：生产 Web` |
| 协议 | 分段：**SFTP / FTP / FTPS** |
| 主机 + 端口 | 同行，端口占位 `22` |
| 认证方式 | 分段：**密码 / SSH 密钥 / 匿名** |
| 用户名 / 密码 | 密码认证下显示 |
| 将密码保存到钥匙串 | 复选，默认勾选 |
| 远程目录 | 占位 `默认为登录目录，如 /var/www/html` |
| 本地目录 | 只读 + `选择…` |

底部动作：`测试连接`（左）｜ `取消` `连接`（右，连接为强调色主按钮）。

## 5. 文件冲突对话框

标题：`远程已存在"main.css"`
说明：`上传会遇到同名文件。请选择如何处理，这次传输共有 5 个冲突。`
对比区两栏：**本地（要上传的）** 带 `较新` 标记、`38.1 KB`、`今天 09:12` ｜ **远程（服务器上的）** `37.4 KB`、`10月13日 21:05`。

单选四策略（比 ADR-0000 I2 多一项）：
1. **覆盖** — 用本地文件替换远程文件
2. **跳过** — 保留远程文件，不上传
3. **重命名** — 内联可编辑输入框，默认建议 `main_13.css`
4. **仅在较新时覆盖** — 本地更新才替换

批量应用：复选 `对其余 4 个冲突执行相同操作`。动作：`取消传输` / `继续`。

## 6. 传输失败对话框

标题：`"main.js" 上传失败`
说明：`传输过程中，服务器断开了连接。已传输 81 KB / 212 KB（38%）。`
可展开 **详细信息** 日志（等宽、带时间戳）：
```
09:14:22　PUT /var/www/html/main.js
09:14:23　已发送 81 KB / 212 KB
09:14:23　错误：连接被对端重置（ECONNRESET）
```
续传提示：`服务器支持断点续传，重试时会从 81 KB 处继续，不会从头开始。`
复选：`以后遇到失败，自动重试 3 次（间隔 5 秒）`
动作：`取消全部传输` / `跳过此文件` / `重试`（重试为主按钮）。

这是 §可观测性"错误码→可读建议映射表"的落地样板：`ECONNRESET` → "服务器断开了连接" + 续传位置说明。

## 7. 设计稿引入的、方案 v2.3 未覆盖的需求

| # | 新增项 | 影响里程碑 | 备注 |
|---|---|---|---|
| U1 | **深色模式**（整套第二调色板） | M2 | 方案全文未提；AppKit `NSOutlineView` 与 SwiftUI 双栈都要跟随 appearance |
| U2 | **强调色可配置**（4 色） | M2 起持续 | 所有自绘色必须走令牌，不能硬编码 |
| U3 | 左侧**站点栏 + 本地位置栏**（220px） | M2 | v2.3 的 M2 只写"双栏 UI" |
| U4 | 工具栏 **`同步` 常驻** | M2 占位、M5 才可用 | 需要禁用态与"未实现"提示策略 |
| U5 | **搜索文件**输入框 | M2 | 需定义是本地过滤还是远端 find |
| U6 | 连接胶囊里的 **RTT（32 ms）** | M1' 采集、M2 展示 | 方案只有心跳，无 RTT |
| U7 | 状态栏 **↑↓ 实时速率** 与 **`加密连接` / `UTF-8`** 指示 | M3 / M2 | UTF-8 指示要把 negotiated charset 暴露到 UI |
| U8 | 队列 **全部/进行中/失败** 筛选 | M3 | |
| U9 | 冲突策略多一项 **"仅在较新时覆盖"** + **批量应用** | M4 | 依赖 `mtimeIsReliable`，不可靠时该选项须禁用 |
| U10 | FTP **匿名**认证方式 | M1' | 认证矩阵要加一档 |
| U11 | 队列行显示 **ETA（剩余 12 秒）** | M3 | 方案有 ETA，设计确认了文案位置 |
