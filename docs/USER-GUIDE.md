## 1. 快速上手与新建连接

### 1.1 协议覆盖
- **SFTP (SSH File Transfer Protocol)**：基于静态编译的 `libssh2 1.11.1` 与 `OpenSSL 3`，支持现代 SSH 算法协商与全链路加密传输；
- **FTP / FTPS (Explicit TLS 1.3)**：基于 macOS 系统原生 `libcurl`，支持明文 FTP 与安全 FTPS（TLS 1.3 强加密握手）。

### 1.2 认证矩阵
1. **密码认证**：连接密码通过安全通道存入 macOS 系统钥匙串 (Keychain)；
2. **私钥认证**：完整支持 OpenSSH 新格式私钥、PEM 格式；如私钥具备密码短语 (Passphrase)，Ferry 会弹出密码框进行解锁；
3. **`ssh-agent` 密钥代理**：自动感知本地运行的 SSH 密钥代理，无需暴露私钥明文；
4. **键盘交互认证 (Keyboard-Interactive)**：动态支持双因子验证 (2FA / OTP) 或服务器自定义多步输入挑战；
5. **FTP 匿名模式**：勾选「匿名用户」即可快速接入公用 FTP 镜像源。

### 1.3 主机密钥信任机制 (TOFU)
- 首次连接远程主机时，Ferry 会弹出公钥指纹卡片（支持 MD5 及 SHA-256 指纹比对），供用户核验；
- 若检测到远程主机公钥指纹与已知记录冲突（防范中间人攻击 DNS 劫持），Ferry 将执行**硬阻断警告**，并提供一键安全移除旧记录的防呆自助机制。

### 1.4 侧边栏与本地快捷位置
- 侧边栏列出系统常用本地位置与保存的站点书签；
- 点击「本地位置」旁的「+」按钮，可添加自定义的工作目录；在快捷条目上点击右键，支持**重命名**、**重新指定目标路径**、**移除**以及**一键恢复系统默认推荐位置**。

## 2. 双栏文件浏览器与常用操作

### 2.1 AppKit 原生渲染与拖拽
- 中央双栏采用 AppKit 原生底层列表渲染，在大规模文件场景下依旧保持毫秒级流畅响应；
- **全拖拽支持**：
  - 本地文件拖拽至远端列表即可直接发起上传；
  - 远端文件拖拽至本地列表即可发起下载；
  - 支持直接从 macOS Finder 外部拖入，或拖出到桌面等外部目录。

### 2.2 常用文件管理操作
- **新建文件夹**：点击工具栏「新建文件夹」图标，在当前激活目录快速创建文件夹；
- **就地重命名**：选中文件后轻按 `Enter` 键，或右键选择「重命名…」，输入新名称后确认；
- **安全删除防护**：右键选中项点击「删除」，系统将弹出包含文件名与数量的二次确认警告对话框，防止手抖误删关键文件；
- **快速预览 (Quick Look)**：选中任意本地或远程文件，轻按 `Space` 空格键，即可就地唤起 macOS 原生预览面板；
- **外部编辑器实时监视**：双击远端文本或脚本文件，Ferry 将使用 macOS 关联应用打开该临时文件；在外部应用中保存 (`⌘S`) 后，Ferry 后台监视器将自动把最新内容静默回传服务器。

### 2.3 路径栏与字符集
- **双端路径可编辑栏**：双栏顶部路径栏展示当前绝对路径，点击可直接激活输入模式，输入目标绝对路径后按回车或切换焦点即可自动前往；
- **快捷键**：按 `⌘⇧G` 唤出「前往文件夹」对话框；按 `⌘⇧.` 即时切换隐藏文件显示状态；
- **字符集实时无损切换**：所有寻址坚持 `wireBytes` 原生字节，在状态栏可随时将远端文件名解码从 UTF-8 切换为 GBK、GB18030 或 Big5，对于无法识别的乱码字节将自动降级为十六进制视图，绝不导致文件名截断损坏。

## 3. 传输队列与断点续传

### 3.1 传输并发与限速
- 按 `⌘J` 或点击工具栏传输徽标展开底部传输队列面板；
- 默认支持 **N=3** 任务并发传输，单任务故障隔离，不影响其他文件传输；
- 支持平滑令牌桶传输限速，兼顾前台浏览与后台下载体验。

### 3.2 暂停、取消与断点续传 (.part)
- **暂停**：传输保留本地 `.part` 临时文件与已下载字节偏移量；网络恢复或空闲时点击继续即可无缝执行断点续传；
- **取消**：在 200ms 内强制拆除阻塞的网络连接，并自动清理目标端临时残余切片；
- **续传置信度自检**：在执行断点续传前，自动比对服务器端当前文件的大小与最后修改时间，避免服务器文件已被他人修改导致拼接损坏；
- **网络退避重试**：精准区分协议错误与网络瞬断，仅对可恢复的网络异常执行 1s / 2s / 4s 指数退避重试。

## 4. 3-Way 文件夹双向同步 (DiffPlan)

### 4.1 核心机制
点击工具栏「双向同步」按钮，可基于三方快照比对引擎（本地当前状态、远端当前状态、基准快照 Baseline Snapshot）对双端文件夹进行差异分析。

### 4.2 冲突判定与 DiffPlan 可视化
- **真值表判定**：精准区分远端文件被删除与网络中断（`notFound` 状态），杜绝断网误判为删除的灾难性事件；
- **DiffPlan 交互式裁决**：
  在同步预览窗口中，对每一处双端并发修改的冲突项提供四种决断：
  1. `本地为准`：强制以上传覆盖远端；
  2. `远端为准`：强制以下载覆盖本地；
  3. `保留双份`：自动分流重命名，双方修改同时保留；
  4. `跳过`：忽略本次冲突，保持现状；
- **删除安全开关**：同步中的删除操作默认关闭，必须用户显式勾选并确认才允许执行删除。

## 6. 故障排查与脱敏诊断报告

### 6.1 常见错误与解决建议
- **`EHOSTUNREACH / ECONNREFUSED`**：
  - 排查服务器防火墙策略（云服务器安全组入方向 22/21 端口）；
  - 检查网络代理设置或 VPN 连通性。
- **`EACCES (Permission Denied)`**：
  - 检查目标路径的用户读写权限 (`chmod / chown`)；
  - 检查 macOS 文件夹权限（如是否授予定位受保护的 Desktop/Documents 权限）。
- **`HostKeyMismatch`**：
  - 远程服务器重装或 IP 更替所致。通过 Ferry 弹窗提示直接点击「一键移除旧信任记录」，再次连接即可重新信任。

### 6.2 一键导出脱敏诊断报告
当遇到难以排查的协议握手、编码或算法协商问题时：
1. 点击顶部菜单栏 **「帮助」 -> 「导出脱敏诊断报告…」**（或在偏好设置及帮助面板中点击该按钮）；
2. 系统将生成一份规范的 JSON 诊断报告，包含当前硬件、macOS 版本、连接协商算法、传输队列快照与错误码排查建议；
3. **数据隐私安全保障**：所有敏感数据（密码、私钥、Token）绝不入日志，用户名实施哈希/掩码保护。
